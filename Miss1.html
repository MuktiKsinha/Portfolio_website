YouTube Sentiment Analyzer

Transforming Audience Insights into Actionable Decisions

Real-time sentiment analysis of YouTube comments, powered by LightGBM and Flask API, giving creators actionable insights without manual review.

📌 Business Problem

Creators struggle to monitor thousands of comments per video, leading to delayed engagement, missed opportunities, and poor moderation of toxic comments. Companies need a solution that automates sentiment detection to make actionable decisions quickly.

🚀 Solution

The YouTube Sentiment Analyzer automates comment analysis with the following features:

  • Real-time comment capture using YouTube Data API v3.
  • Text preprocessing (cleaning, tokenization, vectorization).
  • LightGBM-based sentiment classification (Positive, Neutral, Negative).
  • Immediate display of insights in the Chrome extension UI.
  • Logging predictions & metrics using MLflow for monitoring & compliance.

🧠 Technical Breakdown

  • ML Model: LightGBM trained on large-scale YouTube comment dataset.
  • Vectorizer: Bag-of-Words with additional feature engineering (punctuation, comment length).
  • Deployment: Flask API hosted on AWS EC2 using Docker for scalability.
  • CI/CD: GitHub Actions for automatic testing and deployment.
  • Monitoring: MLflow for experiment tracking, drift detection, and model versioning.

👨‍💻 User Workflow

  1. Install Chrome extension.
  2. Open any YouTube video; comments are auto-captured.
  3. Hover over extension icon to see live sentiment metrics.

Provides immediate insights without leaving the YouTube page.

⚠ Challenges & Mitigation

  • High comment volume → solved with async API processing.
  • Noisy text → solved via preprocessing pipeline (emoji removal, punctuation normalization).
  • Model drift → monitored using MLflow and periodic retraining.
  • Chrome UI integration → lightweight and responsive UI design.
