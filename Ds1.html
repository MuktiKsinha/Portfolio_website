YouTube Sentiment Analyzer

Transforming Audience Insights into Actionable Decisions

Real-time sentiment analysis of YouTube comments. Empower creators with instant insights and actionable decisions without manual review.

View Code View README

📌 Business Problem

Monitoring thousands of YouTube comments manually is slow, error-prone, and expensive. Creators need instant, actionable sentiment insights to engage their audience effectively and prevent toxicity.

🚀 Solution

YouTube Sentiment Analyzer instantly captures comments, analyzes sentiment using LightGBM, and displays actionable insights via a Chrome extension. No manual review needed.

Before

  • Manual comment monitoring
  • Slow insights, missed opportunities
  • High risk of toxic content

After

  • Real-time sentiment insights
  • Instant decision-making
  • Cleaner, healthier community

🧠 Technical Breakdown

  • ML Model: LightGBM trained on large-scale YouTube comment dataset
  • Vectorizer: Bag-of-Words with additional features
  • Deployment: Flask API on AWS EC2 with Docker
  • CI/CD: GitHub Actions for testing & deployment
  • Monitoring: MLflow for tracking & model versioning
